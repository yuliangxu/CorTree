# Reproduce the precision-prior comparisons

These portable R scripts regenerate simulation data and run the corrected
samplers underlying the [precision-prior report](../../docs/sampler-corrections.md).
They require neither private result archives nor Slurm. Generated outputs must
be stored outside this checkout. No study figures, raw DNase data, or fitted
objects are included in the repository.

- [Simulation instructions](SIMULATION.md): 100 datasets at each of
  `N=200,400,600`; corrected flat, bounded uniform, weak soft `s0=0.1`, strong
  soft `s0=0.1`, K-means, PAM, DMM and IndTree. `--all-priors` adds the other
  simulation settings in the full prior study.
- [DNase instructions](DNASE.md): REST/NRF1 with all three initializations,
  optional additional tested settings and non-tree baselines. Supply the
  processed input files separately.
- [Prior API and numerical checks](../../docs/precision-prior-api.md): settings
  for both CorTree and PhyloTree, including the scale hierarchy.

Install the updated package and dependencies using the linked instructions.
Then start with smoke runs and choose a new external directory for each study:

```sh
Rscript reproduction/ghs/simulation.R --output /path/to/simulation --smoke
Rscript reproduction/ghs/simulation.R --output /path/to/simulation --task 1
Rscript reproduction/ghs/simulation.R --output /path/to/simulation --task all
Rscript reproduction/ghs/simulation.R --output /path/to/simulation --summarize

Rscript reproduction/ghs/dnase.R --data-dir /path/to/DNA_data \
  --output /path/to/dnase --dataset REST --init rowsum --prior soft_s0p1 --smoke
```

Full simulation runs can take substantial time. Tasks `1..100`, `101..200` and
`201..300` correspond to `N=200`, `400` and `600`; they may run individually in
an external scheduler. Only complete, validated 100-dataset groups receive a
final mean and SD. Smoke runs are excluded from production summaries.

The scripts preserve the historical generator, initialization and sampler-entry
RNG ordering. Exact numerical replay also depends on R, dependency and compiler
versions; the archived studies used R 4.4.3. Published paper numbers are
historical references and are not regenerated by the corrected code. The new
scripts do not automatically repeat the original REST-first screening controller
or the American Gut analysis. Priors were explored on these same benchmarks;
the results and any reruns are not independent tuning holdouts.

The recorded study environment used R 4.4.3 and these package versions:

| Package | Version |
|---|---|
| Rcpp | 1.0.14 |
| RcppArmadillo | 15.2.4.1 |
| dplyr | 1.1.4 |
| cluster | 2.1.8.1 |
| mclust | 6.1.2 |
| DirichletMultinomial | 1.48.0 |
| ape | 5.8.1 |
| CENTIPEDE | 1.2 |

The scripts record the actual environment and reject mixing incompatible run
protocols in one output directory. They do not change your installed packages.
